# Лабораторна робота №4: Інтерактивна візуалізація та аналіз сигналів

## Опис проекту
Цей проект присвячений розробці інтерактивного інструменту для генерації, візуалізації та обробки гармонічних сигналів із використанням бібліотеки `matplotlib` та її віджетів. Програма дозволяє досліджувати вплив параметрів сигналу, накладати шум та перевіряти ефективність цифрової фільтрації в реальному часі.

## Функціональні можливості
Програма реалізована у вигляді Jupyter Notebook і надає наступні можливості:

- **Генерація гармоніки:** Налаштування амплітуди ($A$), частоти ($f$) та фази ($\phi$) основного сигналу за допомогою інтерактивних повзунків.
- **Моделювання шуму:** Додавання випадкового шуму до чистого сигналу з можливістю регулювання середнього значення та дисперсії.
- **Інтерактивне керування:** - **Sliders:** для плавної зміни параметрів гармоніки та шуму.
  - **Checkboxes:** для перемикання видимості окремих компонентів.
  - **Reset Button:** для миттєвого повернення всіх налаштувань до початкового стану.

## Технічні вимоги
Для коректної роботи проекту необхідно встановити Python 3.x та наступні бібліотеки:
- `numpy`

- `scipy`
