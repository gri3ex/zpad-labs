# Лабораторна робота №7: Computer Vision та багатопотоковість у C++

Цей проєкт реалізує асинхронну детекцію облич у реальному часі за допомогою бібліотеки OpenCV та нейромережі ResNet-10.

## Мета роботи
Поєднання обробки відеопотоку (Computer Vision) з багатопотоковим програмуванням для забезпечення високої продуктивності інтерфейсу (FPS).

## Технології
* **Мова**: C++17
* **Бібліотека CV**: OpenCV 4.12 (модуль dnn)
* **Нейромережа**: ResNet-10 SSD (Caffe model)
* **Система збірки**: CMake

### Для Linux
Програма підтримує повну автоматизацію згідно з ТЗ:

- Відкрийте проєкт у VS Code.

- Налаштуйте шлях до OpenCV у CMakeLists.txt.

- Натисніть F7 для збірки.

- Скопіюйте файли deploy.prototxt та res10_300x300_ssd_iter_140000.caffemodel у папку build/Debug/ (або запустіть через термінал з кореня).

## Архітектура проєкту

Програма побудована за модульним принципом з використанням об'єктно-орієнтованого підходу. Для забезпечення високої продуктивності реалізовано **багатопотокову архітектуру**.

### Основні модулі (Класи)
* **FaceDetector** — ключовий модуль, що керує фоновим потоком (`std::thread`). Виконує інференс нейромережі ResNet-10.
* **CameraProvider** — відповідає за захоплення кадрів з камери за допомогою `cv::VideoCapture`.
* **KeyProcessor** — обробляє ввід з клавіатури та керує станом програми.
* **Display** — відповідає за візуалізацію обробленого кадру та виведення графічних елементів.

### Логіка багатопотоковості
Обробка розділена на два незалежні потоки:
* **Main Thread (UI)**: Головний потік. Зчитує відео, малює рамки облич, відображає результат та обробляє клавіші.
* **Worker Thread**: Фоновий потік. Постійно працює у фоні, приймає копії кадрів та виконує детекцію через `net.forward()`.

> **Синхронізація**: Безпека даних при передачі кадрів та координат між потоками забезпечується механізмом **`std::mutex`**. Це дозволяє уникнути блокування інтерфейсу, навіть якщо детекція займає значний час (додано штучну затримку 500мс для демонстрації).
