# Лабораторна робота №6: Обробка відеопотоку в реальному часі (OpenCV)

Цей проєкт реалізує модульну програму на C++ для захоплення відео з веб-камери, обробки кадрів за допомогою алгоритмів комп'ютерного зору та візуалізації результату. Програма побудована з використанням об'єктно-орієнтованого підходу (ООП) відповідно до вимог.

## 📌 Вимоги до системи
* **Операційна система:** Ubuntu 22.04+ або Windows 10/11.
* **Компілятор:** GCC (Linux) або MSVC 2022 (Windows).
* **Система збірки:** CMake 3.10+.
* **Бібліотеки:** OpenCV 4.x.

---

## Інструкція для Linux (Ubuntu)

Для перевірки роботи на чистій системі використовуйте автоматизовані скрипти. Перед запуском надайте їм права виконання: `chmod +x *.sh`.

1. **Крок 1: Попереднє встановлення залежностей**
   Виконайте скрипт для встановлення бібліотек (`libopencv-dev`, `cmake`, `g++`):
   ```bash
   ./preinstall.sh
2. **Крок 2: Збірка проєкту**
   Запустіть скрипт для автоматичної конфігурації та компіляції:
   ```bash
   ./build.sh
3. **Крок 3: Запуск програми**
   ```bash
   ./run.sh

## Інструкція для Windows (VS Code)

Для успішного запуску на Windows виконайте наступні кроки:

1. **Підготовка:**

Встановіть OpenCV (рекомендований шлях: C:/opencv).
Переконайтеся, що шлях до OpenCV у файлі CMakeLists.txt відповідає вашому: set(OpenCV_DIR "C:/opencv/build").

2. **Збірка у VS Code:**
   - Відкрийте папку проєкту.

   - Натисніть Ctrl + Shift + P -> CMake: Configure.

   - Оберіть Kit: Visual Studio Community 2022 Release - amd64.

   - Натисніть кнопку Build на нижній панелі (або клавішу F7).
  
3. **Важливо (DLL файли):**
   Якщо програма видає помилку про відсутність бібліотек, скопіюйте файл opencv_world4120d.dll (або вашу версію) з папки C:\opencv\build\x64\vc16\bin у папку проєкту build/Debug/ поруч із виконваним файлом lab6_exe.exe.

## Управління
- `1` — Оригінал
- `2` — Gray (чорно-білий)
- `3` — Canny (контури)
- `4` — Blur (розмиття)
- `Esc` — Вихід

## Архітектура проєкту
Програма має модульну структуру:

- CameraProvider: Захоплення кадрів з cv::VideoCapture.
- KeyProcessor: Обробка клавіш, містить enum з режимами.
- FrameProcessor: Обробка зображення в залежності від обраного режиму.
- Display: Відображення результату через cv::imshow.
