# Лабораторна робота №3: Статистичний аналіз та візуалізація даних

Ця робота присвячена дослідженню взаємозв'язків між характеристиками об'єктів на прикладі датасету автомобільних оголошень. Основна увага приділяється кореляційному аналізу, виявленню закономірностей та візуалізації розподілів.

---

## Інструкція з розгортання та запуску

Дотримуйтесь цих кроків, щоб налаштувати середовище та запустити аналіз.

### 1. Підготовка проєкту
Якщо ви ще не завантажили репозиторій, виконайте команду:
```bash
git clone [https://github.com/gri3ex/zpad-labs.git](https://github.com/gri3ex/zpad-labs.git)
cd zpad-labs/lab3
```
### 2. Налаштування віртуального середовища
Це дозволить встановити необхідні версії бібліотек саме для цієї роботи.
### Для Windows:
```bash
python -m venv venv
.\venv\Scripts\activate
```
### Для Linux / macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```
### 3. Встановлення залежностей
Встановіть всі необхідні бібліотеки за допомогою файлу requirements.txt:
```bash
pip install -r requirements.txt
```
### 4. Запуск аналізу
Запустіть Jupyter Notebook для перегляду графіків:
```bash
jupyter notebook
```
### Детальний опис виконаних завдань
### Частина 1: Кореляційний аналіз
* Розраховано матрицю кореляції для визначення лінійної залежності між кількісними показниками авто (потужність, вага, ціна тощо).

* Теплова карта: Побудовано візуальну матрицю за допомогою seaborn. Це дозволило миттєво виявити найсильніші зв'язки (наприклад, між engine-size та price).

* Інтерпретація: Виявлено, що об'єм двигуна та вага авто мають пряму сильну кореляцію з ціною (~0.85), тоді як економічність палива має зворотну залежність.

### Частина 2: Візуалізація розподілів та викидів
* Досліджено структуру даних за допомогою графіків для розуміння того, як розподілені ціни.

* Box Plot: Використано для аналізу цін у розрізі типів приводів та кузовів. Це дозволило чітко побачити "викиди" — аномально дорогі авто в певних категоріях.

* Scatter Plots: Побудовано діаграми розсіювання з лініями регресії для підтвердження гіпотез про вплив кінських сил на ринкову вартість.

### Частина 3: Підготовка даних та категоріальний аналіз
* Обробка пропусків: Очищено датасет від неповних записів, які могли викривити статистичні показники.

* Групування: Створено зведені таблиці для порівняння середньої ціни авто залежно від виробника та типу палива, що виявило цінові сегменти ринку.

### Технічні вимоги:
* Python: 3.9+

* Бібліотеки: Pandas, Seaborn, Matplotlib, Scipy.

* Датасет: automobile_data.csv.
