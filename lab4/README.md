# Лабораторна робота №4: Інтерактивна візуалізація та цифрова фільтрація сигналів

Ця робота присвячена створенню інтерактивного інструменту для аналізу гармонійних сигналів із шумом. Основний фокус — реалізація об'єктно-орієнтованого підходу для побудови графіків та застосування цифрових фільтрів для очищення даних.

---

## Інструкція з розгортання та запуску

Дотримуйтесь цих кроків, щоб налаштувати середовище та запустити інтерактивний додаток.

### 1. Підготовка проєкту
Завантажте репозиторій та перейдіть у відповідну директорію:
```bash
git clone [https://github.com/gri3ex/zpad-labs.git](https://github.com/gri3ex/zpad-labs.git)
cd zpad-labs/lab4
```
### 2. Налаштування віртуального середовища
Це важливо для коректної роботи інтерактивних віджетів Matplotlib.
### Для Windows:
```bash
python -m venv venv
.\venv\Scripts\activate
```
### Для Linux / macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```
### 3. Встановлення залежностей
Встановіть всі необхідні бібліотеки за допомогою файлу requirements.txt:
```bash
pip install -r requirements.txt
```
### 4. Запуск середовища
Відкрийте ноутбук для роботи з графіками:
```bash
jupyter notebook
```
# Детальний опис виконаних завдань
### Частина 1: Генерація та моделювання сигналу
* Реалізовано математичну модель гармонійного коливання з накладанням випадкового шуму.

* Параметризація: Користувач може динамічно змінювати амплітуду, частоту та фазу сигналу.

* Моделювання шуму: Додавання білого шуму для симуляції реальних умов вимірювання фізичних величин.

### Частина 2: Цифрова фільтрація
* Для очищення сигналу від високочастотного шуму застосовано фільтр Баттерворта низьких частот.

* Математична база: Використання функції scipy.signal.butter для розрахунку коефіцієнтів фільтра та lfilter для обробки масиву даних.

* Результат: Ефективне пригнічення шумів при збереженні основної гармонійної складової.

### Частина 3: Інтерактивний інтерфейс
* Створено повноцінний UI-клас для керування графіком без перевантаження коду.

* Віджети: Слайдери для зміни параметрів сигналу та кнопка CheckButtons для ввімкнення/вимкнення шуму та фільтрації.

* Event Handlers: Реалізовано методи зворотного виклику, які автоматично оновлюють графік при кожному русі повзунка.

### Технічні вимоги
* Python: 3.9+

* Бібліотеки: Numpy, Scipy, Matplotlib, Ipympl.

* Особливість: Для роботи слайдерів у ноутбуці використовуйте %matplotlib widget.
