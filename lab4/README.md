# Лабораторна робота №4: Генерація та фільтрація гармонічних сигналів

## Опис проекту
Цей проект демонструє роботу з інтерактивною візуалізацією сигналів у середовищі Jupyter Notebook. Програма дозволяє моделювати фізичні процеси, додавати до них перешкоди (шум) та застосовувати методи цифрової обробки сигналів.

## Інструкція користувача

Після запуску всіх комірок коду з'явиться графічне вікно з інтерактивними елементами керування. Дотримуйтесь наступних кроків для аналізу:

### 1. Налаштування чистого сигналу
* **Slider "Амплітуда":** Змінює висоту хвилі. Використовуйте його, щоб змоделювати потужність сигналу.
* **Slider "Частота":** Змінює кількість коливань за секунду.
* **Результат:** Зелена лінія на графіку миттєво реагує на зміни.

### 2. Додавання зашумлення
* **Slider "Шум (std)":** Регулює рівень середньоквадратичного відхилення шуму. 
* Чим вище значення, тим важче розгледіти основний сигнал за "червоною" зашумленою лінією.

### 3. Керування видимістю (Checkboxes)
У лівій частині графіка розміщено три прапорці:
* **"Чистий":** Показує/ховає ідеальну математичну модель (зелена лінія).
* **"Шум":** Показує/ховає зашумлений сигнал (червона лінія).
* **"Фільтр":** Вмикає відображення результату обробки (синя лінія). 
* *Порада:* Щоб оцінити якість фільтрації, залиште увімкненими лише "Чистий" та "Фільтр".

### 4. Робота з фільтром (п. 5 методички)
Програма використовує фільтр низьких частот (Butterworth filter). 
* Якщо сигнал занадто спотворений, активуйте вкладку "Фільтр" у чекбоксах. 
* Фільтр відсікає високочастотний шум, залишаючи плавно наближену форму оригінального сигналу.

### 5. Скидання параметрів (Reset)
* Якщо ви хочете повернутися до базових налаштувань, передбачених завданням, натисніть кнопку **"Reset"** у нижньому правому куті. Всі повзунки автоматично повернуться у стан `valinit`.
