# Лабораторна робота №2: Обробка та аналіз великих масивів даних

Ця робота присвячена практичним навичкам роботи з бібліотекою **Pandas**, маніпуляціям із великими датасетами, очищенню даних NOAA та порівняльному аналізу методів нормалізації.

---

## Інструкція з розгортання та запуску

Дотримуйтесь цих кроків, щоб налаштувати середовище та запустити код на вашій системі.

### 1. Встановлення Python
Переконайтеся, що у вас встановлено Python версії **3.9 або вище**.
* **Windows:** Завантажте інсталятор з [python.org](https://www.python.org/downloads/) (обов'язково поставте галочку **"Add Python to PATH"** при встановленні).
* **Linux:** Зазвичай встановлений за замовчуванням. Перевірте командою `python3 --version`.
### 2. Клонування проекту
Спершу завантажте репозиторій та перейдіть у директорію другої лабораторної роботи:
```bash
git clone [https://github.com/gri3ex/zpad-labs.git](https://github.com/gri3ex/zpad-labs.git)
cd zpad-labs/lab2
```
### 3. Налаштування віртуального середовища
Віртуальне середовище дозволяє ізолювати залежності цієї роботи від інших проєктів Python у вашій системі.
Для користувачів Windows:
```bash
python -m venv venv
.\venv\Scripts\activate
```
Для користувачів Linux / macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```
### 4. Встановлення залежностей
Встановіть всі необхідні бібліотеки однією командою за допомогою файлу requirements.txt:
```bash
pip install -r requirements.txt
```
### 5. Запуск Jupyter Notebook
Для перегляду та виконання коду запустіть сервер Jupyter:
```bash
jupyter notebook
```
### Детальний опис виконаних завдань
### Частина 1: Очищення та обробка даних NOAA (VHI)
* Робота з даними вегетаційних індексів (Vegetation Health Index). Основна задача полягала у підготовці "брудних" даних до аналізу.

* Механізм очищення: Реалізовано алгоритм видалення технічного тексту та HTML-розмітки, що залишаються при автоматичному вивантаженні даних.

* Валідація типів: Проведено конвертацію стовпців з об'єктного типу у числовий, що дозволило виконувати математичні операції над показниками стану рослинності.

### Частина 2: Аналіз енергоспоживання
* Глибокий аналіз датасету household_power_consumption, що містить дані про споживання електроенергії за кілька років.

* Складна фільтрація: Написано запити для відбору специфічних аномалій споживання (наприклад, активна потужність понад 5 кВт у вечірній час при певних показниках напруги).

* Оптимізація: Для прискорення візуалізації та аналізу застосовано методи проріджування даних, що дозволяє працювати з репрезентативною вибіркою без втрати загальних трендів.

### Частина 3: Порівняльний аналіз нормалізації
* Досліджено два фундаментальні підходи до підготовки числових ознак для моделей машинного навчання:

* MinMaxScaler: Процес "стискання" значень у фіксований діапазон [0, 1]. Це критично для алгоритмів, чутливих до масштабу ознак.

* StandardScaler: Перетворення даних так, щоб середнє значення дорівнювало 0, а стандартне відхилення — 1. Це дозволяє виявити статистичні викиди.
