# Лабораторна робота №5: Інтерактивний вебдодаток для аналізу даних на Streamlit

Ця робота є логічним завершенням циклу, де всі методи обробки (фільтрація, статистика, візуалізація) об'єднані в один інтерактивний інтерфейс. Додаток дозволяє користувачу в реальному часі керувати параметрами аналізу та миттєво бачити результат у браузері.

---

## Інструкція з розгортання та запуску

На відміну від попередніх лаб, цей проєкт запускається як локальний вебсервер.

### 1. Встановлення Python
Переконайтеся, що у вас встановлено Python версії **3.9 або вище**.
* **Windows:** Завантажте інсталятор з [python.org](https://www.python.org/downloads/) (обов'язково поставте галочку **"Add Python to PATH"**).

### 2. Підготовка проєкту
Завантажте репозиторій та перейдіть у папку лаби:
```bash
git clone [https://github.com/gri3ex/zpad-labs.git](https://github.com/gri3ex/zpad-labs.git)
cd zpad-labs/lab5
```
### 3. Налаштування віртуального середовища
### Для Windows:
```bash
python -m venv venv
.\venv\Scripts\activate
```
### Для Linux / macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```
### 4. Встановлення залежностей
Встановіть усі необхідні бібліотеки одним списком:
```bash
pip install -r requirements.txt
```
### 5. Запуск додатка
Важливо: Запуск здійснюється спеціальною командою фреймворку:
```bash
streamlit run app.py
```
Додаток автоматично відкриється у вашому браузері за адресою http://localhost:8501.

# Детальний опис виконаних завдань
### 1. Статистичний аналіз
* В інтерфейс додано функціонал для розрахунку кореляції між числовими атрибутами.

* Коефіцієнт Пірсона: Використовується для виявлення сили лінійного зв'язку між показниками.

* Коефіцієнт Спірмена: Оцінює монотонність залежності, що дозволяє враховувати нелінійні зв'язки та мінімізувати вплив викидів.

### 2. Підготовка даних 
* Реалізовано блок динамічного кодування категоріальних ознак.

* OHE: Функція перетворює текстові категорії (наприклад, назви областей) у набір бінарних колонок. Це демонструє фінальний етап підготовки даних до машинного навчання.

### 3. Інтерактивна візуалізація та UI
* Весь інтерфейс структурований за допомогою вкладок st.tabs:

* Таблиця: Відображення динамічно відфільтрованих даних.

* Графік: Візуалізація часових рядів за допомогою Matplotlib.

* Керування: Використання слайдерів, кнопок скидання та випадаючих списків для фільтрації за регіоном/часом.

### Технічні вимоги
* Python: 3.9+

* Фреймворк: Streamlit.

* Бібліотеки: Pandas, Numpy, Scikit-learn, Matplotlib, Seaborn.
