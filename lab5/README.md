# Лабораторна робота №5: Обмін результатами та інтерактивний аналіз

## Опис
Цей веб-додаток створений за допомогою бібліотеки **Streamlit**. Він дозволяє проводити інтерактивний аналіз індексів VCI, TCI та VHI для 27 областей України, використовуючи дані з Лабораторної роботи №2/

## Функціональні можливості
- **Фільтрація:** вибір показника, області, діапазону тижнів та років.
- **Інтерактивні вкладки:** розділення даних на таблицю, графік динаміки та порівняльний аналіз.
- **Сортування:** можливість сортування даних за зростанням або спаданням. [
- **Reset:** миттєве скидання всіх фільтрів до початкового стану.
